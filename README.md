## About

SKMemory is a universal AI memory system designed to work with any project. It provides persistent, searchable knowledge storage with multi-layer memory organization.

### Key Features

- **Git-based storage** with full version control and audit trail
- **Multi-layer memory** (short-term / mid-term / long-term)
- **Vector search** via Qdrant integration
- **Cursor.ai integration** via `.cursorrules` for automatic context loading
- **Semantic search** and text-based search scripts
- **Auto-sync** to vector database
- **Role-based memory** (dev / ops / sec / ai)
- **Complete AI instructions** for autonomous memory management

### Memory Architecture

```
memory/
├── public/
│   ├── short-term/sessions/    # Session-specific memories
│   ├── mid-term/               # Project-level knowledge
│   ├── long-term/              # Persistent patterns & standards
│   └── roles/                  # Role-specific knowledge
│       ├── dev/
│       ├── ops/
│       ├── sec/
│       └── ai/
└── private/
    ├── short-term/sessions/
    ├── mid-term/
    └── long-term/
```
