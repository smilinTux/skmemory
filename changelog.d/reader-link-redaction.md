A restricted reader no longer learns the ids of hidden memories through link fields. `recall`, `search` and `list_memories` (and so the MCP `memory_recall`, `memory_search` and `memory_list`) drop hidden `related_ids`, `parent_id`, `supersedes_id`, `metadata.superseded_by`, `possible_conflict_with`, `write_triage` and `decomposition.parent_id` via one `MemoryStore.redact_links` helper that uses the same visibility rule as `history()`. Owner output is unchanged (SKMEM-P0-21).
