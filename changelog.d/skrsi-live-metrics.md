New `skrsi/live_bench_metrics.py` turns a live bench `.rows.json`, or the pinned live baseline, into an SKRSI metrics file for target `skmemory-retrieval`, so live runs are recorded the same way as the class bench. An unmeasured kind is null, errored calls are left out of latency, the write-guard invariant is asserted only from the run's own guard record, and `sabotage_tested` stays false until a test proves it. First record: `skrsi/evaluations/skmemory-retrieval-live-20261107.*`, outcome inconclusive (sabotage cap), all five live metrics improved on the 2026-11-06 baseline.
