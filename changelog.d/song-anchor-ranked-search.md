Song anchors: ranked search (`skmemory/song_search.py`) so felt and paraphrased queries find anchors. Field and idf weighted token overlap plus emotion-synonym concepts, offline by default, with an optional dense arm (`--semantic`, embed endpoint) that falls back to lexical on any failure. `skmemory songs search` is ranked by default (`--substring` keeps the old match); `match_anchors_for_feb` gains opt-in `synonyms=`. New `python -m skmemory.eval.song_bench` benchmarks substring vs ranked on a synthetic anchor set (recall@3 and MRR per class).
