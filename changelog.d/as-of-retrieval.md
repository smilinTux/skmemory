`store.search`, `memory_search` and `skmemory search --as-of` take an `as_of` instant and keep only memories valid then (`coalesce(valid_from, created_at) <= as_of` and `valid_to` null or `> as_of`), pushed into the semantic, lexical, lexical_local, graph and temporal arms (SQLite, skmem-pg typed columns or `memory_json`, AGE Cypher) and re-checked on every hydrated row. v1 rows without `valid_from` fall back to `created_at`; a null `valid_to` is open. With no `as_of` there is NO temporal filter, so closed or superseded memories are returned as before. New `store.history`, MCP `memory_history` and `skmemory history <id>` return the supersession chain oldest first; a declared reader gets the chain cut at the first hidden member. The class bench now runs as_of queries with `as_of` and the fixture validity windows (SKMEM-P3-03).
