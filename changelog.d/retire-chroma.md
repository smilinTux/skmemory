- chore(chroma): ChromaDB is retired for good (SKMEM-P5-01). Removed `skmemory/backends/chroma_backend.py`, the `chroma` extra, the `chroma_*` config fields, the selector mapping, the `reindex --vector` flag (use `skmemory sync --vector`) and the `primary_chroma_collection` corpus-registry field. `SKMEMORY_VECTOR_BACKEND=chroma` now fails fast ("ChromaDB has been retired; use pgvector (shared) or the SQLite FTS5 local arm"): non-zero exit on the CLI, red `health`. A stale `chroma_*` key or `chroma` entry in a `skmemory.yaml` is ignored with a one-time warning and never fails, so old node configs cannot break session hooks. No data dir is touched.
