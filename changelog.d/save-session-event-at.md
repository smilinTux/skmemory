`memory_save_session` takes an optional `event_at` (ISO 8601). When given, relative dates in each saved memory ("yesterday", "next Monday", "last week") get the resolved ISO date appended in parentheses, resolved in the timestamp's own UTC offset (no wall clock, no mtime), skipping code spans, URLs and double-quoted text, and idempotent; the memory's `event_at` is set too. Without it the text is saved unchanged. The resolver is `skmemory/dates.py`, a port of skwhisper's `dates.py` kept in parity by tests. `MemoryStore.snapshot` gains an `event_at` argument (SKMEM-P3-05B).
