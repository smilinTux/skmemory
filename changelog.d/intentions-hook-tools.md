- **Intentions: UserPromptSubmit injection and MCP tools (SKMEM-P2-04).** New `skmemory hook user-prompt` runs the no-LLM prefilter on each prompt (scope `{repo: git root basename}`) and prints `Standing intent (from memory <id>): "<title>"` lines (300 chars each, 1200 total, control characters stripped, title quoted as data), or nothing when no intention fires. It is silent under `SKMEMORY_HOOKS=off` and for any declared `SKMEMORY_READER`, and never fails a prompt. `skmemory hooks install` writes a `UserPromptSubmit` entry that runs the stdlib-only `hooks/user_prompt_fast.py` under `python -S`: it exits in a few ms unless the index holds an armed or fired event intention, and only then hands the prompt to `skmemory.hook_cli`. MCP gains `memory_remind` (`due_at` ISO or `in N minutes/hours/days/weeks`, bad input is an error), `memory_intentions` and `memory_intention_done`, all owner-only. A pending intention can now be marked done (new transition row, fixture regenerated through gen_fixtures.py). No live hook config is changed by this change.
