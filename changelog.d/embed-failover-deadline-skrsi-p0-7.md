A wedged primary embed endpoint no longer eats the whole search deadline: on the read path every embed endpoint but the last gets 60 percent of the REMAINING search deadline when it is tried (the last gets all that remains), and an endpoint that just failed is tried last for 60 seconds, using only in-process state (no probe, no extra request). Writes keep the full timeout. `retrieval.jsonl` rows gain two optional fields, `embed_ep` (index of the embed endpoint that answered the semantic arm) and `embed_ep_inflight` (index of the endpoint still in flight when the semantic arm timed out), never a URL.
