New `skmemory.eval.harvest` collects real memory_search and memory_recall queries (owner sessions only, 90 days, de-duplicated, sensitive queries dropped) into a private candidates file, and `skmemory.eval.label` labels them with a citation-gated two-pass judge through skgateway (local route verified from response headers, quotes validated in code, disagreement goes to an `unjudged` bucket reported as missingness). `live_bench --labelled DIR` runs the same arm table against that set and tags the output `evidence_class: live_labelled`, so the result is no longer self-retrieval. Harvested data lives outside the repo (SKMEM-P1-04).
