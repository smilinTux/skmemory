`skmemory graph repair-lineage --apply` no longer aborts on the first failing row (SKMEM-P0-24). Each row is retried once on a fresh connection, then counted in `errors` (with `error_samples`) and skipped; the command exits 1 if any row failed, and a rerun is idempotent (only remaining SUPERSEDES edges are candidates, MERGE runs before DELETE). `_cypher_strict` now refuses a query body containing `$$`.
