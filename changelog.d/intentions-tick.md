- **Intentions time tick (SKMEM-P2-03).** `skmemory intentions tick` fires due time intentions (pending or armed, `due_at` reached, not snoozed) through `sk-alert -g intentions`, delivering first and recording the fire only on success (a crash can duplicate an alert, never lose one). Only the configured tick host (`SKMEMORY_TICK_HOST` / `--tick-host`) delivers. Alert text carries only the intention title and origin memory id. Adds `skmemory intentions done <id>` and example systemd units under `deploy/systemd/` (nothing is installed).
