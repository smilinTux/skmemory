Importance is now written at first index (layer base plus 0.3 x intensity/10, SQLite column only, never the flat file) and raised on each caller-facing reinforcement with diminishing returns (importance += 0.02 * (1 - importance)). Legacy 0.5 rows (never accessed) are recomputed on reindex, and `skmemory importance-backfill` does the same in batches on an existing index without touching flat files. New `skmemory.decay` module defines the none, recency, reinforcement and affect_weighted channels as explicit formulas; `store.search` bends its relevance order by the channel named in `SKMEMORY_DECAY`. Default is OFF (set `SKMEMORY_DECAY=on` or a channel name) because the fusion_bench A/B lowers semantic-class MRR with it on. The decay-v1 eval fixture is regenerated from those formulas (SKMEM-P0-03).
