`scripts/memory-backup.sh` now backs up the whole flat source (adds intentions, ledger, songs, anchors, rituals, wal, dream-catchup, trust, journal.md and the memory/*.json state files) and never the SQLite index. With `MEMORY_BACKUP_RESTIC_ENV` set it also takes an off-site restic snapshot of those paths plus memory/worship-sessions, with 7 daily / 4 weekly / 12 monthly retention, and fails the run if that snapshot fails. `deploy/ops/skmem-pg-backup.sh` gains `SKMEM_BACKUP_OFFBOX=none` (local only on purpose, no warning), skips a tier whose retain is 0, and writes the dump under a .partial name so a failed dump never displaces the last good copy.
