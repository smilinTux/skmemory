New `scripts/memory-backup-all.sh` backs up every agent on the node in one job: each agent home under `~/.skcapstone/agents` that holds memory gets its own GPG tarballs and its own restic tag (`skmem-flat-<agent>`), the shared restic repo is pruned once at the end, one agent failing does not stop the others, and a run that backs up nothing fails. `memory-backup.sh` now names its tarballs and default `BACKUP_BASE` after the agent instead of a hardcoded `lumina-memory`, takes `CLAWD_DIR=none` to leave the workspace md files out, and takes `MEMORY_BACKUP_RESTIC_PRUNE=0` to leave the prune to the caller.
