Every write path now sets `source_tier`: explicit `memory_store` is `user-stated` (unless its source label says web, tool or generator), Telegram, Notion and conversation imports are `user-stated`, hook and `memory_save_session` / `memory_pre_compact` extractions and digests are `self-generated`, and `store.snapshot` takes `source_tier=` (default derived from `source`, unknown labels `self-generated`). Fused search caps `web` and `self-generated` hits to floor(40 percent of limit) slots when higher-tier hits exist; the cap is an occupancy limit, never a filter, so with no (or too few) higher-tier hits the untrusted hits still return in rank order. Legacy schema v1 rows (no tier was ever assigned; the schema default is a placeholder) are NOT capped, except v1 rows from a known generator source such as `skwhisper`. `SKMEMORY_TIER_CAP=off` disables the cap (SKMEM-P3-06).
