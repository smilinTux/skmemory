AGE point-in-time reads (`currently_valid_memories`, `is_currently_valid`, `neighbors`, `supersedes_chain`, superseded-id lookup) no longer compare validity as text in Cypher. They return the raw `valid_from` / `valid_to` / `created_at` and decide on parsed instants, so `+02:00`, `-05:00`, `Z` and `+00:00` stored values are exact at the boundary (a `valid_to` of `...+02:00` against a `Z` as_of used to leave a superseded memory valid).
